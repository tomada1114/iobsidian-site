Engineering Readers: AI in Production

A useful model reply is only one part of a product feature. Quickturn also needs trustworthy grades, bounded spending and tools that respect learner ownership.

13 pagesAbout 51 minEnglish, B2 · explanatory prose

The example application

Quickturn is a fictional language-learning application. A learner answers a card before a timer ends, then reviews progress and mistakes. Its web, iOS and Android clients share an API.

These chapters use that application to explain concrete engineering choices, their costs and the conditions that would justify a different design. Each chapter stands on its own; no conversation or earlier chapter is needed.

How the pages fit together

The pages

  1. Does every AI feature need to be an agent? — Pick the smallest shape that works, and save agents for open-ended tool use.
  2. What am I actually paying for in one LLM call? — Tokens in and out, and why the same prompt can answer differently.
  3. Why does Bedrock want an inference profile, not a model? — The profile decides where a call runs and which feature pays.
  4. Can an LLM return a type instead of a paragraph? — A schema shapes output; domain checks and evaluations test its meaning.
  5. Why not one complete(prompt) function for every feature? — Each task gets a port that owns its prompt, schema and evaluation.
  6. Should the timed drill wait for the grader? — Grade later as a job, and store the first result.
  7. How would we know a prompt change made grading worse? — A gold set and a few metrics turn opinions into numbers.
  8. Where do evals run: in CI, at night or in production? — Each place catches what the others miss.
  9. What if a learner types 'ignore your instructions'? — Limit what a successful attack can do, instead of betting on detection.
  10. Who pays for the tokens, and what stops a runaway bill? — Reservations control learner entitlement; a delayed account guard contains wider spending.
  11. What does AgentCore do that forty lines of code can't? — It rents you the production parts around the agent loop.
  12. When an agent acts for a learner, whose rights does it use? — From the token, never from a tool argument.
  13. Can a machine review the cards a machine wrote? — Calibrate against human decisions for each language pair, and audit the results.

How to read this

Read a chapter in a few minutes, using the diagrams and code examples alongside the explanation. The summaries collect the main decisions; the examples show where those decisions apply.
