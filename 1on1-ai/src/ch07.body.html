How would we know a prompt change made grading worse?

A new prompt produces a few convincing grades. A reviewed evaluation set must show which cases improved, worsened or became less stable before adoption.

01Why evals come first

Reading ten improved-looking grades is useful error analysis, but not a reproducible quality result. Name the failures observed, label representative cases and define what improvement means before adopting a prompt.

An evaluation set becomes the feature's acceptance evidence. It should exercise the real adapter and record the configuration, not a separate copy of a prompt in a notebook.

02Datasets from what exists

Quickturn starts with reviewed alternative answers as positive examples and deliberately perturbed answers as candidate negatives. A person checks perturbations because removing an article or changing a phrase can still produce valid English.

Include empty, oversized, wrong-language, off-task and adversarial inputs. Learner-marked data is useful but noisier than reviewed labels. Card review uses accepted and rejected cards with reasons. Treat each language pair as its own evidence requirement; labels in one pair do not prove another pair's quality.

03The metrics

Agreement measures verdict quality, especially on negatives that should not be accepted. Schema and tag validity expose operational failures. Cost and latency reveal whether a quality gain is worth its price.

MetricWhat it tells you
AgreementHow often the verdict matches the gold label
Flip rateHow often the verdict changes on the same input
Tag precisionOf the tags it gave, how many were right
Tag recallOf the real errors, how many it found
Cost, latencyWhat one graded answer costs, and how long it takes

Repeated grading estimates verdict stability. A mean agreement score can hide a category whose decisions change frequently.

For error tags, precision asks how many emitted tags are right; recall asks how many real errors were found.

Finding 8 true errors among 10 emitted tags gives precision 0.8. If 12 errors were present, recall is about 0.67 and their harmonic-mean F1 is about 0.73. The denominator and label set need to be explicit.

04What the numbers cost

A grader that accepts every positive can score well on a positive-only dataset. Include rejects, borderline cases and failure categories rather than rely on one aggregate metric.

Human labeling costs time, and small sets are noisy. Compare a candidate with a recorded baseline using tolerances justified by repeated runs. A convincing demo is not evidence that a model upgrade preserved policy answers or grading behavior. Real failures should become labeled regression cases.

Summary in three lines

  1. Build the evaluation before the feature; it is the test suite and the definition of done.
  2. Use reviewed positives, candidate negatives, attacks and rejects, checking that each gold label matches the intended rubric.
  3. Track several metrics against a recorded baseline, because any one metric can be gamed.
