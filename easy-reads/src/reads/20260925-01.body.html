Numbers in a tree

A binary search tree stores numbers in an order that helps a computer find them. Each number sits in a box called a node. A node can point to two more nodes: one on the left and one on the right.

At every node, smaller numbers belong on the left. Bigger numbers belong on the right. The first node at the top is called the root. Every search begins there.

Follow the number

Imagine looking for 42. The root holds 50, so 42 must be on the left. You move to the left child. It holds 30, so 42 must be on the right. You keep asking the same question: is the number smaller, bigger, or the same?

If you find 42, the search is over. If you reach an empty place, your number is not in the tree. You do not need to check the parts you passed. You move through the tree one step at a time. At each choice, you throw away one side.

A short path through a big tree

A balanced tree keeps its height small as it grows. It does not mean every node has exactly the same number of values on each side. Different kinds of balanced trees use different rules to stop the tree from becoming too tall.

In a nearly even tree, a thousand numbers take about ten steps to search. A million take about twenty. That is because each step removes a large part of the choices. Other balanced trees may take longer than this example, but their rules still keep the search path short.

When a tree leans

Without rules to control its shape, a tree can become a long line. If you add 1, then 2, then 3, then 4, each new number goes to the right. A search may then check every number along the path.

Many programs use self-balancing trees, such as red-black trees or AVL trees. They adjust their shape as numbers are added. The names are different, and their rules are different, but they share one goal: keep searches quick.

Words to notice

binary search tree
a tree that puts smaller values left and bigger values right
node
one box in a tree that holds a value
root
the node at the top of a tree
balanced
kept short by rules about its shape
one step at a time
doing one small part before the next
throw away
stop keeping something because it is not needed

English to notice

If you reach an empty place, your number is not in the tree.

The if-clause gives a condition. The second clause tells what happens in that case.
