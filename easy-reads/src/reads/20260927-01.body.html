One short command

Many people who write code on a Mac use Homebrew. It is a package manager, a tool that installs other tools for you. You type brew install and a name, like brew install wget. A few seconds later, the new tool is ready.

But what happens in those few seconds? The steps are simple. Homebrew reads a recipe, gets a package, and puts it in one place.

First, a recipe

For each tool, Homebrew has a small text file. Homebrew calls this file a formula, like a recipe in a kitchen. The formula says where the tool comes from. It also lists the other tools it needs to work.

These other tools are called dependencies. If your Mac does not have them yet, Homebrew installs them first. You do not need to find them yourself.

Then, a ready-made package

Many tools start as source code. Someone has to build that code before a computer can run it. Building can take a long time. So Homebrew builds most tools ahead of time for common Macs.

A package that is already built is called a bottle. When a bottle fits your Mac, Homebrew just downloads it and opens it. This is why most installs are fast. If there is no bottle for your Mac, Homebrew builds the tool from the source code on your machine. That is slower, but it still works.

One folder for everything

Homebrew keeps every tool inside one folder that it manages. On newer Macs, this folder is /opt/homebrew. Each tool gets its own place in there. Then Homebrew adds a short link, so you can run the tool by its name.

Because everything is in one place, Homebrew knows what it installed. You can type brew upgrade to update your tools. You can type brew uninstall and a name to remove a tool. Homebrew takes out its files and does not touch the rest of your Mac.

Words to notice

package manager
a tool that installs, updates and removes other tools
formula
Homebrew's small recipe file for one tool
dependencies
other tools that a tool needs to work
source code
the code people write before it is built
bottle
a Homebrew package that is already built

Think about it

What was the last tool you installed on your computer? How did you install it, and how would you remove it?
