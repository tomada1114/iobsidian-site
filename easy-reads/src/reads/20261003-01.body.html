An agent that runs code

Some AI tools only answer questions. An AI agent does more. It can write code, run it, look at the result and try again. This loop helps it fix its own mistakes.

But running code is not always safe. The code can delete files. It can fill the disk. It can send data over the network. And the agent does not always know what its code will do. Sometimes it makes a mistake. Sometimes someone tricks it with a bad instruction.

A small box to play in

So many agents run code in a sandbox. A sandbox is a small, separate space for running code. Think of a sandbox for children in a park. Kids can dig and build there. The sand stays in the box, and the rest of the park stays clean.

A computer sandbox works the same way. The code inside it can only see its own files. It cannot see your photos, your passwords or your other projects. It often cannot use the network, or it can only reach a few places.

Break it, then throw it away

Now imagine the code does something bad. Maybe it deletes every file it can find. In a sandbox, it only deletes the files in the sandbox. Your real computer is fine.

Many sandboxes are also disposable, which means you use them once and then throw them away. When the job is done, the sandbox is gone. The next job starts in a fresh, clean one. A broken sandbox costs almost nothing.

How it is built

Engineers build sandboxes in a few ways. A common one is a container, like one made with Docker. A container shares the computer's core system but keeps its own files apart. Another way is a virtual machine, a whole fake computer inside the real one. It is slower to start, but the wall is stronger.

Some coding agents can also ask you before they run a command. A sandbox and a question work well together. The question catches risky steps you can see. The sandbox catches the ones you miss.

Words to notice

sandbox
a small, separate space for running code safely
disposable
made to use once and then throw away
container
a box for an app with its own files
virtual machine
a fake computer that runs inside a real one
trick
to make someone do something by fooling them
