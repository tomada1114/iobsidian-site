A model with no past

You talk with an AI chat app on Monday. You tell it your name and your job. On Friday, you open a new chat, and it still knows your name. It feels like the AI remembers you.

But the model itself does not remember anything. A model is a big file of numbers. It does not change when you talk to it. After each chat ends, the model forgets everything.

Memory inside one chat

Inside one chat, the model does seem to remember. This is short-term memory. It works in a simple way.

Each time you send a message, the app sends the whole chat to the model again. The model reads all of it from the start. Then it writes the next answer. This text that the model reads is called the context, all the words it can see at one time.

The context has a size limit. A very long chat may not fit. When that happens, the app may drop or shorten the oldest parts. Then the model can lose details from the start of the chat.

Notes saved outside

Long-term memory works in a different way. It lives outside the model. The app saves short notes about you in a normal database, a place to keep data. A note might say, "The user likes short answers."

Sometimes the app writes these notes by itself. Sometimes the model decides what to save, and the app keeps it. Some apps let you see the notes and delete them.

Giving the notes back

When you start a new chat, the app finds the notes about you. It puts them into the context before your first message. The model reads them like any other text. So it can use your name, even though it never learned it.

AI agents for coding often work the same way. A tool may read a file like CLAUDE.md or AGENTS.md at the start of each session. The file tells the agent about the project. The model is new each time, but the notes stay.

Words to notice

model
the part of the AI that reads text and writes answers
context
all the text the model can see at one time
short-term memory
memory that lasts only for a short time
database
a place on a computer to keep data
session
one period of working with a program

If an AI app kept notes about you, what would you want it to save? What would you not want it to save?
