思い出して覚える、勉強の組み立て方第2章 / 全7章

覚えるには、読む時間の一部を、本を閉じて思い出す時間に回します

資料を読む時間を増やしても、覚えている量は思ったほど増えません。この章では、読む時間の一部を、資料を伏せて思い出す時間に回すと、数日後に残る量が増える理由を確かめ、白紙に書き出して照らし合わせる手順を練習します。

読了 約9分練習問題 5問

この章で分かること

  • 同じ40分を、読むだけに使うのと思い出すことにも使うのとで、何が違うのか
  • 思い出すこと自体が、なぜ記憶を強くするのか
  • 白紙に書き出す練習は、どんな手順で進めればよいのか
  • 読む時間と思い出す時間を組み立てる練習（5問）

01同じ40分でも、使い方によって翌週に説明できる量が変わります

小川さんは、家電量販店の空調売り場で働く販売員です。来週から、メーカーの新しいエアコン3機種を売り場に並べることになり、メーカーの資料で各機種の特徴を覚える必要があります。閉店後に使える時間は40分です。

同じ40分を、二通りに書いてみます。一つ目の版の小川さんは、資料を最初から最後まで4回読みます。4回目には、どのページに何が書いてあるかまで頭に浮かぶようになりました。ところが翌週、客から「この二つの機種は何が違うのか」と聞かれると、資料のどこかに書いてあったことは分かるのに、違いを言葉にできません。

二つ目の版の小川さんは、最初の20分で資料を読み、そこで資料を伏せます。残りの20分では、白紙に3機種の名前を書き、それぞれの特徴を思い出せるだけ書き出します。書きながら、客に説明するつもりで小声でつぶやきます。書き終えたら資料を開いて照らし合わせ、抜けていた点に赤で印をつけ、その部分だけを読み直しました。

二つ目の版で小川さんがしたことを、この本では「思い出す練習」と呼びます。本やノートを閉じて、覚えたはずのことを自分の頭から引き出してみる練習です。研究の分野では、アクティブリコールや検索練習という名前で調べられてきました。

02思い出すこと自体が、記憶を強くします

思い出す練習には、覚えているかを確かめる働きに加えて、思い出した内容を後で思い出しやすくする働きがあります。思い出す作業そのものが記憶を強くするこの現象は、テスト効果と呼ばれます。

米国の心理学者 Roediger と Karpicke が2006年に発表した実験では、大学生120人が短い説明文を読みました。その後、同じ文章をもう一度読む人と、文章を見ずに思い出せることを書き出す人に分け、5分後・2日後・1週間後に、文章の内容をどれだけ思い出せるかを調べています。書き出しのときに、正しい答えは見せていません。

5分後のテストでは、もう一度読んだ人のほうが成績はよくなりました。読んだ直後は、文章がまだ頭に残っているからです。ところが2日後と1週間後には、思い出す作業をした人のほうが多くの内容を覚えていました。試験や商談の日は、勉強した5分後ではなく、数日から数週間後にやってきます。そのため、直後の手応えより、数日後に残る量を基準に勉強のやり方を選びます。

思い出そうとすると、もう一つの効果もあります。思い出せない所がはっきりすることです。小川さんが白紙に書き出したとき、3機種のうち一つの省エネ性能が書けませんでした。資料を読んでいるだけでは、どこが書けないかは分かりません。書けなかった所が分かれば、次に読み直す範囲を、資料全体からその部分だけに絞れます。

03白紙に書き出す練習は、五つの手順で進めます

思い出す練習には、問題集を解く、単語カードをめくるなどいろいろな形があります。手元に問題集がない資料や研修テキストでも使えるのが、白紙に書き出すやり方です。次の五つの手順で進めます。

範囲は小さく区切ります。章全体を一度に書き出そうとすると、思い出せない量が多すぎて、照らし合わせに時間がかかります。数ページか、見出し一つ分を目安にします。時間の配分は、読む時間と思い出す時間をおよそ半分ずつにします。小川さんの40分なら、20分読んで20分書き出す配分です。

書き出すときに小声で言うのは、声に出した内容が黙って読んだ内容より記憶に残りやすいからです。MacLeod らの2010年の研究では、単語の一部を声に出して読み、残りを黙読すると、声に出した単語のほうがよく覚えられていました。ただし、この効果は、声に出した部分が他の部分と区別できるときに現れます。全部を声に出すと区別がなくなるので、声に出すのは、言葉にしにくい所や大事な所に絞ります。

白紙に書き出す手順は、机に向かう勉強の時間だけでなく、仕事の合間にも使えます。社内研修を受けた日の帰りの電車で、配られた資料を開かずに、研修の要点を三つ手帳に書いてみます。取引先との打ち合わせの後なら、メモを見る前に、相手が出した条件を思い出して書きます。書けなかった点は、翌朝に資料やメモで確かめます。新しい商品や制度は毎年のように変わるので、勤め先や担当が変わっても、覚え直す場面は続きます。資料を閉じて思い出す手順を一度身につけておくと、どの場面でも同じ手順で覚え直せます。

思い出せないまま粘りすぎない

一度も理解していない内容は、思い出しようがありません。初めて学ぶ範囲では、まず読んで理解する時間が必要です。また、白紙を前に何も出てこない状態で長く考え込むと、時間だけが過ぎます。1〜2分考えて出てこなければ資料を開き、正しい内容を確かめてから、もう一度伏せて言ってみます。

04練習問題

  1. 保険代理店で働く森さんは、新商品の説明資料を覚えるために、毎晩30分、資料を3回読んでいます。同じ30分のまま、思い出す練習を入れた使い方に組み直してください。
  2. 白紙への書き出しを終えた森さんは、資料と照らし合わせて抜けた点に印をつけました。次にすることとして適切なものを一つ選んでください。（a）資料を最初からもう一度通して読む（b）印の所だけを読み直し、もう一度伏せて言ってみる（c）書き出した紙を清書して保存する
  3. 「思い出す練習は、覚えているかを確かめるテストにすぎない。覚えるのはあくまで読む時間だ」という意見の誤りを、研究の結果を使って説明してください。
  4. 研修テキストの1章分を書き出すときに、小声で言う部分を選びます。どんな部分を選び、どんな部分は黙って書けばよいかを、理由とともに答えてください。
  5. 森さんは、取引先との1時間の打ち合わせで、ノートに8行のメモを取りました。メモを清書する代わりに、打ち合わせの内容を覚えるためにできる、5分の思い出す練習を考えてください。

05解答と解説

  1. 解答例：最初の15分で資料を数ページずつ読み、残りの15分で資料を伏せて白紙に書き出し、照らし合わせて抜けた所だけを読み直します。3回読むと、文章への見覚えは強くなりますが、資料を見ずに説明できるかは確かめられません。時間を半分ずつに分けると、勉強の時間を増やさずに思い出す練習を入れられます。
  2. 解答：（b）。照らし合わせで印をつけた所が、まだ思い出せない部分です。（a）のように全体を読み直すと、すでに思い出せる部分にも同じ時間を使ってしまいます。（c）の清書は、目の前の文を写す作業で、思い出す練習になりません。
  3. 解答例：Roediger と Karpicke の2006年の実験では、正しい答えを見せずに思い出して書き出しただけの人が、同じ時間もう一度読んだ人より、2日後と1週間後に多くの内容を覚えていました。思い出す作業は、覚えているかを確かめるだけでなく、後で思い出しやすくする効果も持っています。
  4. 解答例：声に出すのは、言葉にしにくい所や、仕事で人に説明する必要がある大事な所です。用語の一覧や数字の表のように、黙って書いても問題のない所は声に出しません。声に出す効果は、声に出した部分が他の部分と区別できるときに現れるので、全部を声に出すと効果が薄れます。
  5. 解答例：メモを閉じたまま、相手が出した条件と、次に自分がすることを手帳に書き出します。書き終えたらメモを開いて照らし合わせ、抜けていた条件に印をつけます。清書はメモの文を写す作業なので、内容を頭から引き出す機会がありません。照らし合わせで抜けが見つかれば、相手に確認のメールを送るべき点も分かります。

3行まとめ

  1. 資料を閉じて覚えたことを頭から引き出す作業は、記憶を確かめるだけでなく、後で思い出しやすくする効果を持っています。
  2. 研究では、直後のテストではもう一度読んだ人が上回りましたが、2日後と1週間後には、思い出す作業をした人のほうが多くの内容を覚えていました。
  3. 白紙に書き出す練習は、範囲を小さく区切って読み、伏せて書き出し、照らし合わせて抜けた所だけを読み直す手順で、読む時間とおよそ半分ずつに分けて行います。
前へ何度読み返しても覚えられないのは、「見て分かる」と「自分で思い出せる」が別のことだからです 次へ復習は一度にまとめず、日を空けて何回かに分けます
