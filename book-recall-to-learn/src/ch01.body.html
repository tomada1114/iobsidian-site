思い出して覚える、勉強の組み立て方第1章 / 全7章

何度読み返しても覚えられないのは、「見て分かる」と「自分で思い出せる」が別のことだからです

テキストを何度も読み、大事な所に線を引いたのに、問題を前にすると答えが出てこないことがあります。この章では、その原因が、読み返しで育つ記憶と、試験や仕事で使う記憶の違いにあることを確かめ、自分が本当に思い出せるかを確かめる方法を練習します。

読了 約9分練習問題 4問

この章で分かること

  • 3回読んで「分かった」と感じたのに、翌週に答えが出てこないのはなぜか
  • 読み返しや蛍光ペンは、研究でどう評価されているのか
  • 自分が思い出せるかどうかは、どう確かめればよいのか
  • 見て分かることと思い出せることを見分ける練習（4問）

013回読んで分かったつもりでも、問題を前にすると答えが出てきません

田村さんは、不動産会社で賃貸物件の仲介を担当する営業です。会社から宅地建物取引士の資格を取るように勧められ、平日の夜に1時間ずつテキストを読んでいます。今週の範囲は、部屋を貸す人と借りる人の契約に関する章です。

同じ1週間を、二通りに書いてみます。一つ目の版の田村さんは、章を最初から最後まで読み、大事だと思った文に黄色の蛍光ペンを引きます。翌日と翌々日も同じ章を読み返し、3回目には「ここはもう分かった」と感じました。ところが翌週、問題集で同じ範囲の問題を解くと、選択肢のどれもが見覚えのある言葉に見えて、どれが正しいかを決められません。

二つ目の版の田村さんは、章を1回読んだらテキストを閉じます。次に、目次に並ぶ見出しだけを見て、その見出しの下に何が書いてあったかを声に出して言ってみます。三つの見出しのうち、一つは説明できましたが、残りの二つは言葉が出てきません。田村さんは言えなかった二つの見出しに印をつけ、その部分だけを読み直してから、もう一度閉じて言ってみました。

二つの版の田村さんは、同じ時間を勉強に使っています。違いは、テキストを開いたまま読んでいたか、閉じて自分の頭から引き出そうとしたかです。この本では、本やノートを閉じて、覚えたはずのことを自分の頭から引き出してみることを「思い出す練習」と呼びます。研究の分野ではアクティブリコールとも呼ばれます。

02読み返しで育つのは、見て分かる記憶のほうです

記憶の使い方には、少なくとも二つの種類があります。一つは、見せられたときに「これは見たことがある」と分かる使い方で、心理学では再認と呼びます。もう一つは、手がかりなしに自分で思い出して言える使い方で、再生と呼びます。同じ文を何度も読むと、文に見覚えができて、再認はしやすくなります。ところが、試験で記述の問題に答えるときや、仕事で客に説明するときに必要なのは、再生のほうです。

やっかいなのは、文に見覚えがあるという感覚を、自分で思い出せるという感覚と取り違えやすいことです。米国の心理学者 Roediger と Karpicke が2006年に発表した実験では、大学生180人が短い文章を学びました。4回続けて読んだ人、3回読んで1回思い出して書き出した人、1回読んで3回思い出して書き出した人に分け、1週間後に内容をどれだけ思い出せるかを調べています。学び終えた時点で「1週間後も覚えている」といちばん強く予想したのは、4回読んだ人たちでした。

それでも、多くの人は読み返しを選びます。Karpicke らが2009年に大学生177人に勉強のやり方を尋ねた調査では、教科書やノートを読み返すと答えた学生が84%いました。自分でテストをして思い出す練習をすると答えた学生は11%で、それをいちばんの方法に挙げた学生は1%でした。2013年には Dunlosky らの研究者が、よく使われる10の学習法に関する研究をまとめました。その中で、読み返しと、蛍光ペンや下線を引くやり方は、役に立つ度合いが「低い」と評価されています。自分でテストをするやり方と、間隔を空けて学ぶやり方は「高い」と評価されました。

こうした研究から分かるように、勉強の成果は、生まれつきの記憶力の差に加えて、勉強のやり方でも変わります。同じ人が同じ時間を使っても、読み返すか思い出すかで、1週間後に残る量が変わります。記憶力に自信がない人や、学生時代から時間が空いて久しぶりに勉強する人ほど、時間をかける前にやり方を見直す価値があります。

03思い出せるかどうかは、本を閉じて言ってみると分かります

自分が見て分かる段階にいるのか、自分で思い出せる段階にいるのかは、感覚では見分けられません。見分けるには、手がかりを減らした状態で実際に言ってみるしかありません。次の四つの手順で確かめます。

  1. 読み終えたら、本を閉じる。
  2. 目次の見出しだけを見る。
  3. 見出しの下に書いてあった内容を、声に出して言うか、紙に書く。
  4. 言えなかった見出しに印をつけ、その部分だけを読み直して、もう一度閉じて言う。

見出しを見て中身を言えれば、その範囲は自分で思い出せる段階にあります。見出しを見ても「何か書いてあった」としか言えなければ、まだ見て分かる段階です。次の勉強の時間は、印のついた見出しの範囲に使います。

蛍光ペンも、使い方を変えれば思い出す練習の道具になります。線を引いた文を、後で問いの形に書き換えます。たとえば田村さんは、「借りる人は、部屋を普通に使っていて傷んだ部分を、出ていくときに元に戻す義務を負わない」という文に線を引きました。この文の横の余白に、「普通に使っていて傷んだ部分を、借りる人は出ていくときに元に戻す義務を負うか」と書きます。次に読むときは、線を引いた文を手で隠し、余白の問いに答えてから隠した文を見ます。こうすると、線を引いた文を使って、見覚えがあるかを確かめる代わりに、自分で思い出せるかを確かめられます。

読み返しが役に立つ場面

読み返しをすべてやめる必要はありません。初めて読む章で全体の流れをつかむときや、思い出せなかった所の正しい答えを確かめるときは、テキストを読む必要があります。日を空けてから読み返すと、続けて読み返すより効果があるという研究もあります。避けたいのは、思い出せるかを確かめないまま、読み返しだけで勉強を終えることです。

04練習問題

  1. 次の勉強のやり方を、「見て分かる記憶を育てている」ものと「自分で思い出す記憶を育てている」ものに分けてください。（a）テキストの重要な文に線を引く（b）研修資料を閉じて、要点を同僚に口頭で説明する（c）ノートをきれいに清書する（d）問題集の問題を、答えを隠して解く（e）単語帳を表と裏を同時に見ながらめくる
  2. 次の文に蛍光ペンで線を引きました。後で思い出す練習に使えるように、余白に書く問いを作ってください。「会議の議事録は、会議の翌営業日の正午までに参加者全員に送る」
  3. 小売店の店長の藤井さんは、新しい防犯マニュアルを3回読み、「もう全部頭に入った」と感じています。藤井さんが、本当に思い出せるかを5分で確かめる方法を書いてください。
  4. 「思い出す練習が大事なら、テキストは1回も読み返さないほうがよい」という意見に対して、どう答えますか。読み返しが必要な場面を一つ挙げて説明してください。

05解答と解説

  1. 解答：見て分かる記憶を育てているのは（a）（c）（e）、自分で思い出す記憶を育てているのは（b）（d）です。（a）と（c）は、目の前にある文を扱う作業で、頭から何かを引き出す必要がありません。（e）は単語帳を使っていても、裏の答えが同時に見えているので、思い出す前に答えを見てしまいます。表だけを見て答えを言ってから裏返せば、（e）も思い出す練習に変わります。
  2. 解答例：「議事録は、いつまでに、誰に送るか」。期限と送り先の二つが問いに入っていると、答えるときに両方を思い出す必要があります。「議事録について何が決まっているか」のような広すぎる問いでは、答えが合っているかを自分で判定しにくくなります。
  3. 解答例：マニュアルを閉じ、目次の見出しだけを見て、各見出しの下に書いてあった手順を声に出して言います。言えなかった見出しに印をつけ、その部分だけを読み直します。3回読んだ後の「頭に入った」という感覚は、マニュアルの文に見覚えがあることから来ている可能性があります。その感覚だけでは、不審な人を見かけたときに、手順を自分で思い出せるかは分かりません。
  4. 解答例：初めて読む内容は、まず読んで理解しないと思い出しようがないので、最初の1回は読む必要があります。また、思い出せなかった所の正しい答えを確かめるときにも、テキストを開いて読みます。避けるべきなのは読み返すこと自体ではなく、思い出せるかを確かめずに、読み返しだけで勉強を終えることです。

3行まとめ

  1. 同じ文を読み返すと文に見覚えができて「分かった」と感じますが、それは見て分かる記憶で、試験や仕事で必要な、自分で思い出す記憶とは別のものです。
  2. 研究では、読み返しや蛍光ペンは長く覚えておく効果が低く、本を閉じて思い出す練習を多くした人ほど、1週間後に多くの内容を覚えていました。
  3. 思い出せるかどうかは、本を閉じて見出しから中身を言ってみると確かめられ、言えなかった所から次の勉強を始めます。
