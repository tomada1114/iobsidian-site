思い出して覚える、勉強の組み立て方第7章 / 全7章

勉強の成果は、睡眠と、気の散らない場所と、知りたい気持ちで変わります

仕事をしながら勉強する人は、睡眠を削って時間を作りがちです。この章では、学んだ後の睡眠、勉強中に目に入る物、勉強する内容への興味が、覚えられる量をどう変えるかを確かめ、勉強を始める前に整える三つの準備を練習します。年齢や記憶力を理由にあきらめる前に、変えられる条件がどれだけあるかも扱います。

読了 約9分練習問題 4問

この章で分かること

  • 睡眠を削って作った勉強時間は、なぜ思ったほど成果につながらないのか
  • 勉強中に目に入る物と、知りたい気持ちは、覚える量をどう変えるのか
  • 勉強を始める前に、何を整えればよいのか
  • 年齢や記憶力に自信がない人は、何から変えればよいのか
  • 勉強の条件を整える練習（4問）

01睡眠を削り、通知の届く机で勉強した時間は、翌日にあまり残りません

岡田さんは、食品メーカーで商品企画を担当する40代の社員です。売上や調査のデータを読む仕事が増え、いずれは転職も考えられるように、統計の知識を問う検定試験を受けることにしました。勉強に使えるのは平日の夜か朝で、家族が寝た後か起きる前になります。

同じ平日を、二通りに書いてみます。一つ目の版の岡田さんは、夜11時から1時まで勉強します。スマートフォンは机の上に置いたままで、通知が届くたびに画面を見て、仕事の連絡に返事をすることもあります。朝は6時に起きるので、睡眠は5時間です。翌日の昼休みに前夜の内容を思い出そうとすると、勉強した範囲の見出しは浮かぶのに、中身がほとんど出てきません。

二つ目の版の岡田さんは、夜11時に寝て朝6時に起きると決め、7時間の睡眠をとります。勉強は朝6時15分からの30分です。スマートフォンは寝室に置いたまま、居間の机に向かいます。勉強を始める前に、ノートの1行目に「今日知りたいこと」を問いの形で書きます。この日は「平均が同じ二つのデータは、何で見分ければよいか」と書きました。勉強の時間は一つ目の版より短いのに、昼休みには、朝に学んだ内容を見ずに説明できました。

02学んだ後の睡眠は、覚えたことを長く残る形に整えます

覚えたばかりの記憶は不安定で、時間をかけて長く残る形に整えられていきます。この働きを記憶の固定と呼びます。Diekelmann と Born が2010年に睡眠と記憶の研究をまとめた論文では、学習の後の睡眠が記憶の固定を助けることが、多くの研究から示されています。睡眠を削って勉強の時間を増やすと、学んだ内容を整える時間のほうが減ってしまいます。

必要な睡眠の長さには目安があります。米国睡眠医学会と睡眠研究学会は2015年に、成人は健康のために、毎晩7時間以上の睡眠を習慣的にとるべきだとする声明を出しました。厚生労働省の「健康づくりのための睡眠ガイド2023」は、成人について、6時間以上を目安に睡眠時間を確保することを勧めています。どちらの目安から見ても、5時間の睡眠は足りていません。

勉強の時間を作るときは、睡眠時間から削るのではなく、寝る時刻と起きる時刻を先に決め、残った時間に勉強を入れます。岡田さんが夜の2時間を朝の30分に変えたのは、この順番で予定を組み直したからです。短い時間でも、本やノートを閉じて覚えたことを頭から引き出す「思い出す練習」に使えば、読むだけの2時間より多くが残りやすくなります。

03気が散る物を遠ざけ、知りたい問いを先に書きます

勉強中に別のことをすると、覚えられる量は減ります。カナダの研究者 Sana らが2013年に発表した実験では、大学生が模擬の講義を聞き、直後にテストを受けました。講義中にノートパソコンで講義と関係のない作業をした学生は、しなかった学生よりテストの成績が11%低くなりました。さらに、そうした作業をする人の画面が見える席に座っていた学生も、見えない席の学生より17%低くなりました。自分が操作しなくても、目に入る画面に注意が向くためと考えられます。岡田さんの机の上で通知が光るスマートフォンも、同じように注意を引きます。

反対に、覚える量を増やす気持ちの状態もあります。米国の研究者 Gruber らが2014年に発表した実験では、参加者が雑学の問題を見て、答えをどのくらい知りたいかを評価した後で、答えを見ました。後のテストでは、答えを強く知りたいと感じた問題の答えのほうが、よく思い出されました。

勉強の内容に、いつも強い興味を持てるとは限りません。それでも、勉強を始める前に「今日知りたいこと」を問いの形で書くと、その日の内容を、答えを探しながら読むことになります。岡田さんは、統計の教科書のばらつきの章を読む前に、「平均が同じ二つのデータは、何で見分ければよいか」と書きました。この問いは、仕事で二つの店の売上を比べたときに実際に困ったことから作ったものです。

勉強を始める前の準備は、次の三つにまとめられます。

  1. 寝る時刻と起きる時刻を先に決め、残った時間に勉強を入れる。
  2. 通知を切り、スマートフォンを別の部屋か、手の届かない所に置く。
  3. 勉強の前に、今日知りたいことを問いの形で1行書く。

04年齢や記憶力を理由にする前に、方法と条件を変えます

仕事をしながら勉強を続けていると、思うように覚えられない理由を、年齢や生まれつきの記憶力に求めたくなります。ただ、覚えられる量を左右する条件の多くは、自分で変えられます。たとえば Roediger と Karpicke が2006年に発表した実験では、学生が同じ文章を同じ時間学びました。もう一度読んだ人より、文章を見ずに思い出して書き出した人のほうが、1週間後に多くの内容を覚えていました。睡眠の長さ、机の上にある物、勉強の前に書く問いも、同じように自分で変えられる条件です。

働き方が変わり、一つの会社で同じ仕事を続けるとは限らなくなると、新しい分野の知識を覚え直す機会は何度も来ます。転職や異動のたびに、仕事を続けながら短い時間で覚える必要があります。睡眠を削って時間を増やすより、決まった時刻に眠り、通知の届かない机で、知りたい問いを書いてから思い出す練習をするほうが、限られた時間で多くが残ります。

目安どおりにいかない時期の考え方

必要な睡眠の長さには個人差があり、長く眠るほどよいわけではありません。仕事の繁忙期や、子どもや家族の世話がある時期には、決まった時刻に眠れないこともあります。そうした時期は、勉強の時間を無理に確保するより、通勤の数分で前日の内容を思い出すなど、短い思い出す練習を優先します。

05練習問題

  1. 保険会社で働く斎藤さんの1日の予定は、次のとおりです。勉強の効果を下げている所を二つ見つけ、直し方を書いてください。「夜12時から1時半まで勉強し、6時に起きる。勉強中はスマートフォンで音楽を流し、メッセージが届いたらその場で返す」
  2. 斎藤さんは、平日に勉強の時間を30分しか作れません。「30分では意味がないので、週末にまとめて勉強する」と言っています。どう助言しますか。
  3. 斎藤さんが勉強している社会保険の制度の章は、斎藤さんにとって興味の持てない内容です。仕事の場面と結びつけて、勉強の前に書く「今日知りたいこと」の問いを一つ作ってください。
  4. 「もう40代なので、若い人のようには覚えられない。勉強しても無駄だ」という同僚に、変えられる条件の例を挙げて答えてください。

06解答と解説

  1. 解答例：一つは睡眠で、1時半に寝て6時に起きると4時間半しか眠れません。寝る時刻と起きる時刻を先に決め、7時間ほどの睡眠をとったうえで、残った時間に勉強を入れます。もう一つはスマートフォンで、メッセージに返すたびに勉強から注意が離れます。通知を切って別の部屋に置き、音楽が必要なら勉強と別の機器で流します。
  2. 解答例：平日の30分を、本やノートを閉じて前日までの内容を思い出す練習に使うよう助言します。週末にまとめて勉強すると、平日の間に何日も思い出す機会がありません。30分でも、間隔を空けて思い出す機会を平日に作ると、週末に学んだ内容が次の週末まで残りやすくなります。
  3. 解答例：「お客さんから、会社を辞めた後の健康保険はどうなるのかと聞かれたら、何と答えればよいか」。実際に仕事で聞かれそうな問いにすると、章の内容を、答えを探しながら読むことになります。
  4. 解答例：覚えられる量は、年齢だけでなく、勉強のやり方や睡眠、勉強する場所でも変わります。たとえば同じ時間を使っても、読み返すより、本を閉じて思い出して書き出すほうが、1週間後に多くが残るという実験があります。年齢は変えられませんが、やり方と睡眠と机の上の物は、今日から変えられます。

3行まとめ

  1. 学んだ後の睡眠は覚えたことを長く残る形に整えるので、睡眠を削って勉強の時間を作ると、整える時間のほうが減ってしまいます。
  2. 勉強中に目に入る画面は覚える量を減らし、答えを知りたいという気持ちは覚える量を増やすので、通知を遠ざけ、勉強の前に知りたい問いを書きます。
  3. 年齢や記憶力は変えられなくても、勉強のやり方、睡眠、机の上の物、知りたい問いは自分で変えられ、それが限られた時間で覚え直し続ける土台になります。
