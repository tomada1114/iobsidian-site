似た種類の問題は、まとめて解かず、混ぜて解きます

問題集を単元の順に解くとよく解けるのに、単元名のない試験問題になると、どの解き方を使えばよいか迷うことがあります。この章では、種類の違う問題を混ぜて練習すると、問題を見て種類を見分ける力がつく理由を確かめ、問題の並べ方を組み直す手順を練習します。

読了 約9分練習問題 5問

この章で分かること

  • 単元ごとに解けるのに、試験で解き方を選べないのはなぜか
  • 混ぜて解くと、練習と試験の成績はそれぞれどう変わるのか
  • 問題はどんな手順で混ぜればよいのか
  • 問題の並べ方を組み直す練習（5問）

01単元ごとに解けていても、単元名のない問題では解き方を選べません

吉田さんは、機械メーカーの経理部に配属されて2年目です。上司に勧められて、簿記の資格試験を受けることにしました。問題集は「現金と預金」「売掛金と買掛金」「固定資産」「決算の整理」のように単元ごとに分かれていて、各単元の解説の後に、その単元の問題が10問ずつ並んでいます。

同じ問題集の使い方を、二通りに書いてみます。一つ目の版の吉田さんは、単元の順に解説を読み、その単元の10問を続けて解きます。どの単元でも、2問目あたりから解き方が分かり、残りの問題はほとんど正解できました。ところが模擬試験では、問題に単元名が書かれていません。取引の説明文を読んでも、どの単元の処理を使えばよいかが決められず、時間が足りなくなりました。

二つ目の版の吉田さんは、四つの単元の解説を一通り読み、各単元の問題を1問ずつ解いて解き方を確かめます。その後は、四つの単元から問題を集め、順番を混ぜて解きます。解く前には、問題の余白に「これは何の単元の問題か」を一言書きます。練習中は間違いが増え、正解できる割合は一つ目の版より低くなりました。それでも模擬試験では、問題文を読んで、どの処理を使うかを選べるようになっていました。

種類の違う問題を、順番を混ぜて練習するやり方を、インターリービング、または交互練習と呼びます。

02混ぜると練習の成績は下がり、1週間後の成績は上がります

単元ごとにまとめて解くと、どの解き方を使うかは、単元名を見た時点で決まっています。そのため、10問を解いても、解き方の手順は練習できますが、問題を見て解き方を選ぶ練習はできません。混ぜて解くと、1問ごとに「これはどの種類の問題か」を見分ける必要があり、見分ける練習が加わります。混ぜた並びでは、同じ種類の問題の間に別の種類の問題が挟まるので、同じ種類の問題に戻ってきたときに、解き方を頭から引き出し直す作業も起こります。

米国の研究者 Rohrer と Taylor が2007年に発表した実験では、大学生が4種類の立体の体積の求め方を学び、練習問題を解きました。種類ごとにまとめて解く人と、種類を混ぜて解く人に分け、練習中の正答率と、1週間後のテストの正答率を比べています。

練習中の正答率だけを見ると、まとめて解くほうが効果的に見えます。1週間後のテストでは、その順位が逆になりました。似た結果は、問題を解く練習以外でも報告されています。Kornell と Bjork が2008年に発表した実験では、参加者が何人かの画家の作風を、絵を見て学びました。同じ画家の絵を続けて見るより、他の画家の絵と混ぜて見たほうが、初めて見る絵の画家を当てる成績がよくなりました。2013年に Dunlosky らが学習法の研究をまとめたときも、交互練習は役に立つ度合いが「中程度」と評価されています。

仕事の場面も、単元名つきではやってきません。経理の担当者の机に届く伝票には、どの処理を使うかは書かれていません。営業の担当者が受ける問い合わせにも、値引きの相談なのか、納期の相談なのかは書かれていません。混ぜて練習することは、目の前の状況から種類を見分ける練習でもあります。

03問題は一通り学んでから混ぜ、解く前に種類を一言書きます

混ぜて解く練習は、次の手順で組み立てます。

問題集の問題番号を使えば、新しい問題を用意しなくても混ぜられます。吉田さんは、四つの単元の問題番号を小さな紙に書いてよく混ぜ、引いた順に解きました。答え合わせでは、答えが合っていたかに加えて、余白に書いた単元名が合っていたかも確かめます。単元名を取り違えた問題は、どこで取り違えたかを1行書いておくと、似た単元の見分け方が自分の言葉で残ります。吉田さんのノートには、「代金を後で受け取る約束の取引なのに、現金の単元だと思った。『月末に受け取る』という言葉を見落とした」という1行が残りました。次に似た問題を見たとき、吉田さんは支払いの時期を表す言葉を先に探すようになりました。

混ぜるのが早すぎる場合と、混ぜても意味がない場合

初めて学ぶ単元では、解き方そのものがまだ身についていないので、まずその単元の問題をまとめて解きます。混ぜるのは、各単元の解き方を一通り使えるようになってからです。また、混ぜて効果があると確かめられているのは、立体の体積の求め方や画家の作風のように、見分けが必要な似た種類の問題です。簿記と英語のように関係のない科目を一つの時間に混ぜて効果があるかは、分かっていません。

04練習問題

  1. 不動産会社の清水さんは、物件の広さ・家賃・初期費用の三つの計算を練習しています。問題集では、広さの問題が5問、家賃の問題が5問、初期費用の問題が5問の順に並んでいます。三つの計算の解き方を一通り覚えた後の、15問の並べ方を書いてください。
  2. 清水さんは、混ぜて解いた日の正答率が、まとめて解いた日より20ポイント低かったので、まとめて解く方法に戻そうとしています。どう助言しますか。
  3. 次の場面のうち、混ぜて解く練習を始めるのが早すぎるものを選び、理由を答えてください。（a）三つの計算の解説を今日初めて読んだ（b）三つの計算をそれぞれ5問ずつ解いて、解き方を説明できる
  4. 電話で問い合わせを受ける仕事に就いた人が、問い合わせを「注文の変更」「返品」「請求の確認」の三つに見分ける練習をします。混ぜて練習する方法を考えてください。
  5. 次の二つの練習のうち、混ぜて解く効果が期待できるのはどちらですか。理由も答えてください。（a）見積書の値引き計算と、税込み価格の計算と、送料の計算の問題を混ぜて解く（b）簿記の問題と、英単語のカードを、1問ずつ交互に解く

05解答と解説

  1. 解答例：同じ種類が続かないように、広さ・初期費用・家賃・広さ・家賃・初期費用……のように並べます。15問の番号を紙に書いて混ぜ、引いた順に解く方法でもかまいません。解く前には、余白に「広さ」「家賃」「初期費用」のどれの問題かを書きます。
  2. 解答例：練習中の正答率が下がるのは、混ぜて解いたときに普通に起こることです。Rohrer と Taylor の実験でも、練習中の正答率は混ぜた人のほうが低かったのに、1週間後のテストでは、混ぜた人がまとめた人の3倍ほど正解しました。練習中の出来ではなく、数日後の出来で方法を比べるように助言します。
  3. 解答：（a）。解説を初めて読んだ段階では、それぞれの解き方がまだ身についていません。その段階で混ぜると、どの解き方を使うかを見分ける以前に、解き方そのものが分からずに止まってしまいます。まず各計算をまとめて解き、解き方を説明できるようになってから混ぜます。
  4. 解答例：過去の問い合わせの記録から、三つの種類の問い合わせを数件ずつ選び、種類を伏せてカードに書き、混ぜて1枚ずつ読みます。読んだらすぐに種類を言い、裏に書いた正しい種類と照らし合わせます。取り違えたカードには、どの言葉で取り違えたかを書いておきます。実際の電話も種類を名乗ってはかかってこないので、混ぜた順で見分ける練習が仕事の場面に近くなります。
  5. 解答：（a）。値引き・税込み価格・送料の計算は、どれも見積書の金額を求める似た種類の問題で、問題文を読んでどの計算を使うかを見分ける必要があります。混ぜて解くと、その見分ける練習が加わります。（b）の簿記と英単語は、取り違える心配のない別の内容なので、交互に解いても見分ける練習にはならず、効果があるかは分かっていません。

3行まとめ

  1. 単元ごとにまとめて解くと、解き方は単元名で決まってしまうので、問題を見てどの解き方を使うかを選ぶ練習になりません。
  2. 種類の違う問題を混ぜて解くと練習中の正答率は下がりますが、研究では1週間後のテストの成績が大きく上がりました。
  3. 混ぜるのは各単元の解き方を一通り身につけてからにし、解く前に問題の種類を一言書いて、答え合わせでは種類の見分けも確かめます。
