# ヨハネの福音書

全21章を、出来事と対話の流れを追える現代日本語の読み物に再構成。目次は `ch00.html`。
新約シリーズの入口は `../`。

各章は聖書の章・節範囲を示した物語本文と、章末の二列の整理表で構成する。
原文の出来事・会話・主張を各章末の照合先で確かめ、背景や解釈の説明を本文の流れに混ぜすぎない。
資料と再構成の方針は `src/ch00.body.html` に記載する。

Site 内で `python3 new-testament/john/src/build.py` を実行してビルドする。
CSS は reading-page-designing の正本をコピーする。
