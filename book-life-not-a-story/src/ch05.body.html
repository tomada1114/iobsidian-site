人生を物語にしない生き方第5章 / 全7章

正解のキャリアは、どこかに隠れているのか

「自分に合う正解の会社がどこかにある」と考えて条件を絞り込む見方が、どんな前提に立っているのかを説明できるようになります。迷いを「調べれば答えが出る問題」と「試しながら付き合う問い」に分ける方法も分かります。

読了 約8分打ち合わせスペース、金曜

この章で分かること

  • 正解の会社を探すと、何をしていることになるのか
  • 世の中をパズルとして見ると、何が起きるのか
  • 答えのない迷いは、どう扱えばいいのか

金曜の午後、総務部の奥の打ち合わせスペース。早瀬は寝不足の顔をしている。

01正解の会社を探して、夜中まで比べていた

早

早瀬: 昨日の夜、転職サイトの適職診断と年収の比較を、夜中の2時まで見ていました。

志

志摩: 眠そうな顔をしているのは、そのせいですね。何を探していたんですか。

早

早瀬: 正解の会社、ですかね。自分に合う会社がどこかに一つあって、条件を全部入れれば出てくる気がして。

志

志摩: 診断は、いくつやってみたの？

早

早瀬: 5つです。それが、結果が全部違ったんです。営業向き、企画向き、事務向き、それから教える仕事向きと、職人向き。

志

志摩: キャリアを、パズルとして解こうとしていたんですね。

早

早瀬: パズル、ですか。

志

志摩: 答えが一つ決まっていて、手がかりを正しく組み合わせればそこに着く遊びのことです。クロスワードや数独がそうですね。

早

早瀬: ジグソーパズルみたいに、全部のピースがはまる場所がある。

志

志摩: そうです。自分の経歴を一本の筋にまとめて意味をつけること、つまり物語化と、少し似ているんですよね。物語は結末に向けて出来事をつなぎ、パズルは答えに向けて手がかりをつなぎます。

早

早瀬: それでも、条件で絞り込むのは合理的だと思います。どこが問題なんですか。

志

志摩: 答えがある問題なら合理的です。キャリアの場合は、答えが一つあるという前提のほうを疑ってみたいんです。

早

早瀬: そういえば、うちの部の宇佐美もパズルが好きかもしれません。人事異動の発表があるたびに、「本当の理由」を推理して、部のチャットに長文を書くんです。

志

志摩: 異動を長く担当してきた私から見ると、そういう推理はたいてい外れています。

早

早瀬: 外れているんですか。読むと、すごく説得力があるんですけど。

志

志摩: 手がかりを全部つなげて一つの答えにしているので、説得力が出るんです。実際の異動は、欠員、本人の希望、家庭の事情、たまたまの時期が混ざって決まります。

早

早瀬: 理由が一つではない、ということですね。

志

志摩: 一つの理由で説明できる異動のほうが、むしろ少ないです。

早

早瀬: 宇佐美の推理を読むと、会社の中で何か大きな計画が動いているように思えてきます。

志

志摩: 実際の人事は、もっと散らかっているんですよね。年度の途中で誰かが辞めると、空いた席を埋めるために、急いで何人かを動かします。

早

早瀬: 計画というより、穴埋めの連続ですか。

志

志摩: 穴埋めも多いです。ただ、穴埋めで動いた人が新しい部署で力を発揮することもあって、散らかった中から思わぬ組み合わせが生まれます。

02世の中をパズルとして見ると、手がかりを全部つなげてしまう

志

志摩: パズルには、答えが一つあって、手がかりはすべてその答えにつながっている、という前提があります。この前提を世の中に当てはめると、何が起きると思いますか。

早

早瀬: 関係のない出来事まで、答えの手がかりに見えてくる気がします。

志

志摩: そうです。部長が廊下で誰かと話していた、会議室に予約が入っていた。全部が「異動の伏線」に見えてきます。

早

早瀬: ドラマの考察みたいですね。最終回の前に、視聴者が細かい場面から犯人を当てるような。

志

志摩: ドラマには作った人がいて、答えが用意されていますから、考察が楽しめます。困るのは、作った人のいない現実にも同じ見方を向けたときです。

早

早瀬: 陰謀論も、そういう形をしていますか。

志

志摩: 同じ形です。偶然や、ばらばらの理由で起きたことを、一つの隠れた答えにつなげてしまいます。

早

早瀬: つながらない出来事は、どうなるんですか。

志

志摩: 無視されるか、「まだ解けていない手がかり」として扱われます。答えがないかもしれない、とは考えないんです。

早

早瀬: 答えがないかもしれない、と考えるのは、少し怖い気がします。

志

志摩: 怖いと感じるのは自然です。答えがないということは、自分で決めて、決めたあとも確かめ続けるということですから。

早

早瀬: パズルなら、解けたところで終わりにできますもんね。

志

志摩: パズルとして見ることは、世の中を、人が解けるくらい単純だと見くびることでもあります。違いを並べてみますね。

早

早瀬: 診断が5つとも違ったのは、答えが一つではなかったからでしょうか。

志

志摩: 診断はそれぞれ別の物差しで測っています。違う結果が出るのは当然で、どれか一つが正解というわけではありません。

早

早瀬: 正直に言うと、外れた4つを無視して、気に入った1つだけを信じようとしていました。

志

志摩: 気に入った1つを答えにして、残りを「まだ解けていない手がかり」にしていたわけですね。

早

早瀬: 宇佐美のことを言えないですね。

志

志摩: 早瀬さんだけではありません。人は、ばらばらの情報を前にすると、一つの答えにまとめたくなります。まとまると安心できますから。

早

早瀬: 安心したくて、パズルにしていたんですね。

志

志摩: 夜中の2時まで比べていたのも、答えが出れば眠れると思ったからではないかな。

早

早瀬: そのとおりです。結局、答えは出なくて眠れませんでしたけど。

03「解く問題」と「試す問い」に分ける

志

志摩: 迷いを、二つに分けてみましょう。調べれば答えが出る「解く問題」と、答えのない「試す問い」です。

早

早瀬: 解く問題には、どんなものがありますか。

志

志摩: 転職したときの手取りの年収、退職金がいくらになるか、新しい会社までの通勤時間。調べれば答えが出ます。

早

早瀬: 試す問いのほうは？

志

志摩: 自分はどんな仕事に面白さを感じるか、どんな人と働きたいか。こちらは、いくら調べても答えが出ません。

早

早瀬: 答えが出ないなら、どうすればいいんでしょう。

志

志摩: 1か月で確かめられる小さな実験を、一つ決めます。気になる業界の勉強会に一度出る。関心のある会社で働く人に、30分だけ話を聞く。

早

早瀬: 社内でもできそうですね。ほかの部署の会議を見学させてもらうとか。

志

志摩: いいですね。実験をしたら、結果を見て問いを直します。流れを描きます。

早

早瀬: 実験をしても、答えは出ないんですよね。

志

志摩: 答えは出ません。出るのは、問いの形の変化です。「企画の仕事がしたいか」が、「人の動きを見て、その場で直す仕事がしたいか」に変わる、というふうに。

早

早瀬: 私の場合、営業時代に展示会のブースを設営するのが好きだったので、それも試す問いの材料になりそうです。

志

志摩: 問いが具体的になるほど、次の実験も選びやすくなります。展示会を手伝える部署や会社に、話を聞きに行けますから。

早

早瀬: 実験をする時間がない、という人もいそうです。

志

志摩: 30分話を聞くくらいなら、1か月のうちにどこかで取れることが多いです。夜中まで調べ物をする時間を、一回分だけ実験に回す、と考えてもいいですね。

早

早瀬: 正解の会社を探すより、問いを具体的にするほうが先なんですね。

志

志摩: 問いが具体的になってから会社を探すと、比べる条件も自分で決められます。診断の結果に条件を決めてもらわずにすみます。

気をつけたいこと

手続き、計算、条件の比較のように答えがある問題は、パズルとして解くのが正しい扱い方です。何もかもを答えのない問いとして扱うと、退職の届け出のように期限のある手続きまで決まらなくなります。迷いをまず二つに分けるのは、そのためです。

早

早瀬: 宇佐美には、何と言えばいいでしょう。推理をやめろとは言いにくいです。

志

志摩: 推理を遊びとして楽しむのはかまいません。ただ、推理を事実のようにチャットに流すと、名前を出された人が困ります。

早

早瀬: 書くときは「ここからは推理です」と断ってもらう、とかですか。

志

志摩: それなら、読む人も遊びだと分かりますね。名前を出された人が、職場で根拠のない噂の的になるのも防げます。

早

早瀬: 宇佐美が、推理が外れたときに「外れた」と書いてくれたら、もっと面白くなりそうです。

志

志摩: 外れた推理を見直すのは、答えのない問いの扱い方そのものですね。推理を出して、結果を見て、考えを直す。それなら、パズルを解くのとは違う、問いとの付き合い方になります。

04早瀬さんが説明し直す

志

志摩: 転職先を探して同じように夜更かししている友だちがいたら、どう話しますか。

早

早瀬: 正解の会社を探すのは、キャリアを答えの決まったパズルとして解こうとしていることだ、と伝えます。

早

早瀬: パズルとして見ると、手がかりを全部つなげて一つの答えにしてしまうし、合わない手がかりは無視してしまう。

志

志摩: そこから、どうしますか。

早

早瀬: 迷いを、調べれば答えが出る問題と、答えのない問いに分けます。年収や通勤時間は調べて解けばいい。

早

早瀬: どんな仕事が面白いかのような問いには、1か月でできる実験を一つ決めて、結果を見て問いを直します。

志

志摩: 実験の結果で、問いの言葉がどう変わったかを書き残すように、と付け加えてください。書き残しておくと、正解の会社を探していたときより、自分が何を確かめてきたかが見えるようになります。

3行まとめ

  1. 自分に合う正解の会社が一つあると考えて条件を絞り込むのは、キャリアを答えの決まったパズルとして解こうとしていることになる。
  2. 世の中をパズルとして見ると、偶然やばらばらの理由で起きたことまで一つの隠れた答えにつなげ、つながらないものを無視してしまう。
  3. 迷いを、調べれば答えが出る問題と、答えのない問いに分け、答えのない問いには1か月で確かめられる小さな実験を決めて、結果を見て問いを直していく。
