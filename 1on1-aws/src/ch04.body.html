Why doesn't Quickturn have a VPC?

The web app and API need one browser origin, but neither needs a private database connection. That distinction shapes Quickturn’s delivery and networking.

01The edge

CloudFront serves the browser app from edge locations. Its S3 origin blocks public access and grants the intended distribution access through origin access control. HTTPS is required for the viewer and origin paths.

A small edge function rewrites client-side routes to the static app entry page. That makes a direct visit to a settings route work without exposing the bucket as a public website.

02One origin for two backends

One domain routes static files to S3 and /api to the API. Static assets can be cached; learner-specific API responses use a disabled caching policy and the required header, cookie and query forwarding.

The browser sees one origin, simplifying cookies and avoiding cross-origin browser requests. Native clients are not governed by browser CORS in the same way. A separate API hostname remains an option if its operational benefits justify the additional web configuration.

03What a VPC is for

A VPC defines an AWS network with subnets, routing and security groups. A subnet is public when its route table provides an internet-gateway route; actual public reachability also depends on addresses and security controls. Private resources may use NAT or service endpoints for outbound access.

Quickturn calls managed public service endpoints with signed, IAM-authorized requests and has no private database to reach. It therefore avoids VPC networking costs for this path. This does not mean “public endpoint” makes the application's table public, or that IAM alone covers every application threat.

04When you do need a VPC

A VPC is useful when reaching private RDS databases, internal corporate services or networks connected by VPN or Direct Connect. Regulatory and organizational requirements can also constrain network paths.

Quickturn instead combines edge controls, IAM and application authentication for its present architecture. WAF rules can limit abusive request rates but do not authenticate learners or enforce per-user model budgets. Add private networking when a concrete resource or policy needs it, and include its fixed and transfer costs in the decision.

Summary in three lines

  1. A CDN can serve a private bucket and route /api/* to the API, so the browser sees one origin.
  2. Quickturn uses IAM plus application authentication and authorization; its present request path has no resource requiring a customer VPC.
  3. Add a VPC when you must reach something private, and budget for NAT gateways and endpoints billed by the hour.
